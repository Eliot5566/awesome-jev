# Ecosystem review: September 20, 2026

This is a delta review over the [September 19 research pass](2026-09-19.md). Upstream dates in this note use UTC.

## Scope and method

- Confirmed that `cobanov/awesome-jev` had no open pull requests or issues at the start of the review. Recently merged community pull requests were already present on `main`.
- Compared the current list with `valentynkit/awesome-jev-typesafe`, `MrJev/awesome-jev`, `AbdelStark/awesome-typesafe`, and `Anil-matcha/awesome-jev-by-typesafe`. Directory descriptions were treated as discovery leads, not implementation evidence.
- Ran fresh GitHub repository searches for Jev, TypeSafe, and System One projects, then read the selected projects' READMEs and relevant source files at the commits pinned below.
- Added 10 upstream framework integrations and 10 community projects or studies. The community catalog now has 155 entries. Provider pages and cookbooks are counted separately.
- Replaced the earlier Verdict entry with its 2.0 successor rather than listing both generations.
- Review was read-only for upstream projects. No paid inference, package installation, browser or device execution, robotics simulation, or benchmark rerun was performed.

## First-party and provider changes

[Netlify AI Gateway](https://www.netlify.com/changelog/typesafe-jev-ai-gateway/) now documents access to Jev from Netlify Functions through `@typesafe-ai/sdk`, with gateway credentials and billing handled by Netlify.

OpenRouter published two implementation guides. [Gate Agent Tool Calls with Jev](https://openrouter.ai/docs/cookbook/building-agents/gate-tool-calls-with-jev) combines deterministic checks with Noul probabilities and explicit approve, block, and review bands. [Build a Verified Cascade](https://openrouter.ai/docs/cookbook/evaluate-and-optimize/jev-verified-cascade) uses Jev to check a cheaper model's draft before accepting it or escalating. These are provider recipes, not independent security or quality guarantees.

## What changed in the ecosystem

**Frameworks:** Jev support has moved beyond standalone demos. LangChain Python and JavaScript, Pydantic AI, LiteLLM, Rig, Composio, Effect, Ax, and TanStack AI contain inspectable integrations. BAML's implementation is on its v1 nightly line. A default-branch integration does not by itself establish that a stable package release contains it.

**Applications:** the new projects cover semantic grep, read-only email triage, production-dashboard classification, generative painting, and a simulated robot workbench. World Monitor and Inbox Zero are established applications with small, bounded Jev integrations rather than Jev-native products.

**Open models:** `open-jev` uses shared-prefix continuation scoring on MLX and documents its zero-shot calibration limits. JevForge exposes a broader data, training, evaluation, and serving pipeline. Verdict 2.0 replaces the older Verdict listing. Project-reported metrics remain local to each repository's data and protocol.

**Evaluation:** `jev-rerank-bench` keeps raw responses and tests order sensitivity and no-relevant-document cases across 14 datasets. Jev Capability Atlas separates recorded runs, third-party evidence, translations, and synthesis. Inclusion does not imply that this review reran either study.

## Exclusions

The broad search returned many generated scaffolds, duplicate directories, thin API wrappers, and repositories whose README mentioned Jev without an inspectable decision path. They were not added merely for recency or stars. Small projects were included only when the implementation or evaluation artifact contributed a distinct, inspectable pattern.
